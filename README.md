## 📌 About the Project
A comprehensive, advanced web application developed as a cumulative project bridging fundamental CRUD operations with modern, real-world industry requirements. 

This system integrates hardware-level browser capabilities, asynchronous background processing, real-time communication, and third-party API services to handle complex workflows such as smart queuing, location-based attendance, and automated point of sales (POS).

---

## ✨ Key Features
- 🔐 **Secure Authentication:** Single Sign-On (SSO) Google IdP integrated with dynamic OTP verification via Email.
- 📄 **Smart Document Generator:** Dynamic HTML to PDF conversion for certificates and official letters, complete with 1D Barcode & 2D QR Code integration.
- 📍 **Location-Based Attendance:** High-accuracy GPS tracking using the Haversine Formula to validate sales visits.
- 🛒 **Point of Sales (POS) & E-Receipt:** Interactive cart management with Midtrans Payment Gateway integration (QRIS/Virtual Account) and automated QR e-receipts.
- 📡 **Real-Time Queue System:** Unidirectional Server-Sent Events (SSE) broadcasting integrated with Web Speech API (Text-to-Speech) for automated calling.
- 📱 **Web Hardware API Integration:** Direct hardware access via browser for Camera (Snapshot/Webcam) and Web NFC API (Smart Card Reader).
- ⚡ **Asynchronous UI/UX:** Seamless Client-Side DOM manipulation using jQuery AJAX, Axios, Select2, and DataTables for a fast, no-refresh experience.
